# 시간 폴짝 (Time Hop)

7살 아이가 **시간이 얼마나 지났는지** 계산하는 법을 배우는 웹 게임이에요.
개구리 퐁이가 연잎을 폴짝폴짝 건너며 문제를 작은 단계로 나눠 풀어요.

예: 오후 6시 20분 → 8시 40분
1. 6시 20분 → 7시: 40분
2. 7시 → 8시: 1시간
3. 8시 → 8시 40분: 40분
4. 분 더하기: 40 + 40 = 80분
5. 80분 = 1시간 20분
6. 모두 합쳐서 2시간 20분

- 틀리면 시계 긴바늘이 5분씩(아주 어려움에서는 1분씩도) 움직이며 천천히 세어 보여줘요.
- 난이도: 쉬움(10분 단위) · 어려움(5분 단위) · 아주 어려움(1분 단위)
- 아이패드 가로·세로 모두 스크롤 없이 한 화면에 맞춰져요.

## 만들기 프롬프트

```text
7살용 경과 시간 학습 게임을 HTML로 만들어줘(한국어, 아이패드).
예: 6시 20분→8시 40분이면 단계별로 묻기: ①6:20→7:00 몇 분 ②7:00→8:00 몇 시간 ③8:00→8:40 몇 분 ④분 더하기(40+40=80) ⑤80분=1시간 20분 ⑥합계 2시간 20분. 딱 60분이면 "60분=1시간"으로 묻기.
랜덤 문제, 난이도 3개(10분/5분/1분 단위), 1~4시간 길이.
틀리면 시계 긴바늘이 5분씩 움직이며 천천히 세어 보여주고, 60분이 되면 1시간으로 합쳐지는 장면도 보여줘.
귀여운 개구리가 연잎 타임라인을 점프하며 진행하고 말풍선으로 설명.
분은 주황, 시간은 파랑. 큰 키패드, 별 점수, 효과음. 스크롤 없이 한 화면.
```
