# 공룡알 구구단 (Dino Egg Math)

구구단(곱셈·나눗셈)을 풀어 공룡 알을 부화시키는 어린이용 웹 게임이에요.

- 정답 화산 돌을 알에게 주면 알이 따뜻해지고, 다 따뜻해지면 공룡이 태어나요.
- 공룡 50종 도감, 마당에 10마리가 모이면 학교로 보내기
- 곱셈 / 나눗셈 / 섞어서, 난이도 쉬움·보통·어려움, 연습할 단 선택
- 한국어 / English

`index.html` 파일 하나로 실행돼요. 진행 기록은 각 기기의 브라우저에 저장돼요.
